Add a stock

The Bloomberg data comes from Excel, so a new stock is added in the workbook:

  1. Open SYZ_ADVISORY_VOL.xlsx on the terminal, sheet Focus list or Master list.
  2. In the first empty row, type the name and the Bloomberg ticker (and the ISIN on the master list).
  3. Copy the formulas from the row above into the new row, then save (Ctrl + S).

Keep it live

This page updates each time Excel saves the file. To save it automatically every minute while it is open, add this macro once (Alt + F11 → Insert → Module, paste, then Alt + F8 → SyzAutoSave → Run; keep the file as .xlsm):

Sub SyzAutoSave()
    ThisWorkbook.Save
    Application.OnTime Now + TimeSerial(0, 1, 0), "SyzAutoSave"
End Sub

Currency is inferred from the Bloomberg exchange code (SW = CHF, LN = GBp, …), as the workbook does not store it. For Bloomberg's own value, add a column with =BDP(ticker,"CRNCY") headed Ccy on the Master list or Focus list: this page will use it.

Data: Bloomberg values saved in the Excel workbook on this terminal, for the logged-in user only. Do not share this page's data. Vols in %. Expected daily move = IV 3M / √252.
