# data/

Not in git, on purpose:

- `focus_list.csv` (`name,ticker,region,industry,cons_upside,next_results`) and
  `master_list.csv` (`name,isin,ticker`): the stock lists, internal to the advisory team.
- `demo_snapshot.json`: Bloomberg values from the workbook, for demo mode. Bloomberg data must not
  be published.
- `alert_log.csv`: written by the tool.

They come with the tool's zip; keep them on the terminal PC.
