# Final quality control

Read this before handing a deck over. Tick every line; anything unresolved goes into the hand-over message.

## Automatic (the build prints these)

- [ ] QC: 0 errors (package integrity, every part well-formed, no shape off the page or over the footer, Nunito Sans for text and Nunito Bold for titles and the cover only, no leaked `None`/`nan`, every content slide titled, chart caches valid)
- [ ] QC warnings reviewed in the preview (text that may overflow a box)
- [ ] Every open point resolved or deliberately left visible on the sources slide

## Accuracy

- [ ] Each product's terms match its source (spot-check coupon, barrier, strike, dates, underlyings against the factsheet)
- [ ] Initial levels: no "factsheet vs Yahoo" gap flags left unexplained
- [ ] Products flagged "Called?" or "Matured" confirmed with the issuer or the custody statement
- [ ] Nominals and values match the custody statement; weights sum to 100 %
- [ ] FX: rates used (sources slide) are sensible for the as-of date
- [ ] Headlines agree with the tables underneath (same figures, same rounding)

## Calculations

- [ ] Barrier distances in points of initial; American barriers touched since fixing are shown as touched
- [ ] Scenario table excludes called / matured products (noted in the open points)
- [ ] Portfolio performance is labelled "illustrative" (review) or "back-test" (proposal) and in the reporting currency
- [ ] Average coupon is nominal-weighted in the reporting currency

## Formatting and readability

- [ ] One message per slide: a short label title (no QC "title is" warning) and a takeaway line with the figure
- [ ] Messages one line each, three per box at most; no sentence repeating a figure on the slide
- [ ] No orphan slides (an empty assessment slide means messages are missing — add them or accept that it is skipped)
- [ ] No filled grey boxes; tables readable (≥ 10 pt where possible), no text over the footer, one-line captions

## Research

- [ ] Each research line has a source and a date, and reads as that source's view
- [ ] No research item left "not shown" by mistake (open points)
- [ ] The sources used are listed in the hand-over with links
- [ ] Agenda page numbers match the slides

## Client suitability and compliance

- [ ] Pseudonym only — no client name, account number or address anywhere (slides, notes, file name, file properties)
- [ ] Balanced: risks next to opportunities, downside scenarios shown, issuer credit risk mentioned
- [ ] No promises ("guaranteed", "will"), past performance described as past, third-party views attributed
- [ ] Important Information and offices pages present at the end
- [ ] User reminded to file the deck in approved storage (not left in downloads or the workspace)
